实现日期：2026-09-18。真实照片及地球物种范围更新：2026-09-25。

当前范围：只保留交互地球上有动物标记的 31 个拼图。额外的三角龙关卡已取消，目录、解锁计数及旧地址均不再提供该关卡；历史资产和存档不主动删除。

## 入口与玩法

探索页「筛选和搜索物种」内的「拼起生命的故事」进入 `#puzzles`。有设计图标的物种详情提供该物种的直接入口。

当前 31 个 3×3 动物拼图。后台按地球标记条件检查坐标、设计绑定、图标及非空圆圈状态，并要求对应物种实拍照片。每关的拼块、完整参考、封面及知识卡均来自同一张对应物种照片，地球图标保持原状。照片按学名及源记录编号精确绑定，绑定失配时不回退到卡通或相似物种。

拼图上方始终显示实拍参考缩略图，点击它或「查看照片」可查看完整照片。图片保持原始宽高比；来源区提供作者、许可及原始页面链接。图片全部本地保存、解码和校验，不依赖客户端访问境外图床。爪哇犀为历史黑白照片，北方毛鼻袋熊为政府红外监测照片，均在界面说明。

拼块按随机顺序放在网格中。拖到另一块上交换，或依次点击两块交换；Tab / 方向键移动焦点，Enter / Space 选择，Escape 取消。编号提供辅助排序。可以查看照片和使用「帮我拼一块」提示。

所有拼块位置正确后展示完整图像，并解锁 3 张知识卡。重新开始只重置拼图，保留知识卡。未完成也会自动保存；退出、刷新或服务器重启后可以继续。

## 保存与解锁

- 客户端提交交换位置和进度版本；服务端保存排列并判断完成。客户端传入 `completed`、`board` 等字段不能直接解锁。
- SQLite `puzzle` 记录保存排列、移动次数、提示次数、版本与首次解锁时间。版本冲突返回 409，界面重载最近进度后继续。
- 访客通过 HttpOnly / SameSite=Strict Cookie 关联独立进度；清除 Cookie 后无法找回。已登录用户以账号保存，可在同一部署的其他设备继续。
- 访客与账号进度分别保存，当前不自动合并。注销账号会清除账号所属拼图记录。
- 目录仅返回挑战概要；未解锁的详情不返回知识卡正文。物种下架后对应挑战不再公开。
- 所有修改继续遵守应用的同源与 `X-AniKind` 校验。
