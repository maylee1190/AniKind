# 拼图实拍照片与授权

核对日期：2026-09-25。当前 31 种地球动物的本地照片用于拼块、完整参考、关卡封面和知识卡。三角龙关卡已取消，其照片及来源仅保留在历史资产清单中。地图继续使用原有设计图标。

## 使用方式

- 照片按物种源记录编号和学名共同绑定，不使用相似动物或卡通替代。
- 原始 JPEG 保存在 `public/assets/wildlife-photos/`；作者、来源、许可、实际尺寸及 SHA-256 记录在 `server/wildlife-photos.json`。
- 页面仅按比例缩放、用拼块遮罩展示，不改变动物外形。游戏中提供摄影来源和许可链接，封面显示作者及许可。
- 爪哇犀采用 1884 年伦敦动物园历史照片；北方毛鼻袋熊采用昆士兰政府红外监测实拍；三角龙采用博物馆骨架展陈实拍，明确标注不是活体照片或外貌复原图。
- 北方毛鼻袋熊未使用有物种标注争议的 Wikimedia 默认照片；小头鼠海豚未使用默认分布示意图，改为 NOAA 实拍。

## 维护与校验

1. `scripts/prepare-wildlife-photos.ps1` 查询候选照片并缓存；默认候选需经人工核对。
2. `scripts/fetch-wildlife-photos.ps1` 应用经过核对的物种覆盖规则，下载照片并生成清单。
3. `scripts/check-wildlife-photos.py` 使用 Pillow 解码、记录真实宽高及 SHA-256，并生成联系表供逐图复核；下载后必须运行。
4. `node --test tests/puzzles.test.mjs` 验证绑定、授权字段、本地资产和解锁流程。

运行时不访问境外图床。资产替换后需重启服务以重新加载清单。再次替换图片时，应重新核对物种、许可、署名及照片实际内容。
