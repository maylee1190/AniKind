# 中文与英文

实现日期：2026-10-29。

页面顶部的「中文 / English」覆盖纪念、探索、个人设置、拼图收藏、拼图和弹窗。语言保存在浏览器本地，链接也接受 `?lang=en` 或 `?lang=zh-CN`，刷新后保持所选语言。

切换会重新载入当前页面，并通过会话存储恢复地球经纬度、缩放及搜索筛选。拼图进度和知识卡归属仍由原有服务器存档管理，不按语言另建副本；保存过程中会先提示等待。正在编辑的模态表单打开时，背景语言按钮不可操作，避免意外丢失输入。

## 翻译范围与维护

- `public/js/i18n.js` 提供 `t` 和 `tr`：前者翻译已编写的界面文字，后者只翻译模板静态文本，再插入动态值。HTML 的表单值、ID、事件标识和链接不参与翻译。
- `public/js/locales/en.js` 是界面及错误提示词库，模板参数使用 `{0}` 等占位符。`tr` 不替代 HTML 转义，所有用户内容仍通过原有 `E` 处理。
- `public/js/locales/species-en.js` 翻译既有 40 条动物资料的名称、栖息地、威胁及来源说明，未变更保护等级、照片、坐标或原有待复核说明。
- `/api/species` 增加基于学名匹配的英文名称检索；中文、英文及学名可定位同一记录。数据库原文保持原样。
- 31 个地球动物拼图共用原有照片与进度，完整参考、操作反馈及 3 张知识卡均提供英文。三角龙关卡仍不可用。
- 私人记忆、用户名、宠物名、文件名及表单内容不会自动翻译。新添的编辑内容没有经核对的译文时保留原文。
- 语言入口始终展示两种语言的原生名称；资料管理中的中文字段和删除账户确认短语保留必要原文，避免更改后台值的语义。

## 验证

39 项自动化测试通过，包括中英文和学名搜索一致、全部 40 条资料有英文内容、私有文本不被替换、锁定知识卡不因语言切换而泄露，以及语言切换共用拼图进度。另在浏览器验证语言持久化、拼块交换、知识卡翻页，并检查手机窄屏与电脑布局。
