## 浏览器人工联调

使用 Codex 内置浏览器，本机地址 `http://127.0.0.1:4173`。

- 查看手机首页：Figma 宠物抠图、紫 / 黄氛围、真实文字、带中文标签的悬浮导航。
- 查看生态地图：可见地球、分类文本、地区示意、计数与物种列表。
- 输入 `panda`，列表与统计从 3 条变为 1 条；打开大熊猫资料查看来源、评估日期未核实说明。
- 完成本地虚构测试账户注册，创建无照片宠物档案。
- 输入中文记忆，保存文字草稿、关闭、重新打开并恢复原文字；保存后进入相册。
- 收藏记忆后按钮变为「取消收藏」，版本更新；未知日期保留「日期待补充」。
- 在「我的」看到隐私开关、授权记录、素材管理、导出与删除入口。
- 重启服务后，测试账户会话、档案、记忆仍可读取。
- 提交导出后出现真实下载入口。接口测试另验证压缩包内容。
- 320、402、840、1280 CSS px 下检查文档宽度，没有横向溢出。手机首页和地图已目视检查。
- 已检查的浏览器流程未发现 error / warn 日志。

浏览器文件选择自动化出现超时和不稳定响应，因此**未把浏览器文件选择链路或带照片生成的完整 UI 链路记录为通过**；照片上传、格式校验、去重、任务执行与确认由 HTTP 集成测试覆盖。没有采用截图或静态按钮替代真实后端测试。
